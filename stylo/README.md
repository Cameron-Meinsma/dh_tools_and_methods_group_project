# Stylometry using the Stylo package in R

This subdirectory contains the following:

- `clean_data.py` removes the clutter from the Project Gutenberg .txt files for more accurate stylometry.

- The `data` folfer contains the results from webscraping the novels. It also contains a python script that adds a prefix to the filenames for identifying categories in Stylo.

- The `corpus` folder contains the all the .txt files with prefixes that Stylo uses for analysis.

- The two .csv files are nodes and edges tables generated by stylo that will be used for network analysis in Gephi.

- `stylo.r` contains the R script to run stylometric analysis on the ``corpus` folder. The configuration can be found in this script or in `stylo_config.txt`.

- The PNG file contains the result of the Stylo analysis in the form of a bootstrap consensus tree.
